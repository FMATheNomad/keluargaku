# KeluargaKu

Aplikasi web manajemen keluarga dengan Python Flask backend dan SQLite.

## Fitur

- Dashboard ringkasan keluarga
- Manajemen tugas dengan progres
- Sticky notes digital
- Pencatatan finansial/transaksi
- Kontak darurat
- Daftar belanja dinamis
- Pengumuman penting
- Anggota keluarga
- Acara & tradisi tahunan

## Teknologi

- Python Flask (backend)
- SQLite (database)
- Bootstrap 5 (UI)
- Flatpickr (datepicker)
- Vanilla JavaScript (frontend logic)

## Cara Menjalankan

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# atau venv\Scripts\activate  # Windows
pip install -r requirements.txt
python app.py
```

Buka `http://localhost:5000` di browser.
