# KeluargaKu

## Deskripsi

**KeluargaKu** adalah sebuah aplikasi berbasis web yang dirancang untuk membantu manajemen kegiatan keluarga, termasuk tugas, pengumuman penting, pengaturan keuangan, dan banyak fitur lainnya. Proyek ini menggunakan teknologi modern seperti Bootstrap 5, Google Fonts, dan Flatpickr untuk memberikan antarmuka yang responsif dan ramah pengguna. 

## Fitur yang Direncanakan

- **Dashboard Utama**: Menyediakan ringkasan kegiatan dan pengingat penting keluarga.
- **Manajemen Tugas**: Formulir untuk menambah dan melacak tugas keluarga.
- **Sticky Notes**: Menyimpan catatan penting dalam bentuk sticky notes digital.
- **Finansial**: Melacak transaksi keuangan dan pengeluaran keluarga.
- **Kontak Darurat**: Menyimpan informasi kontak darurat yang penting.
- **Daftar Belanja**: Membuat dan mengelola daftar belanjaan keluarga.
- **Media Galeri**: Menampilkan galeri media keluarga (sedang dalam pengembangan).
- **Berkas Penting**: Menyimpan berkas penting keluarga (sedang dalam pengembangan).
- **Acara dan Tradisi Tahunan**: Mengelola acara dan tradisi tahunan keluarga (sedang dalam pengembangan).
- **Pengaturan Anggota Keluarga**: Mengelola pengaturan anggota keluarga (sedang dalam pengembangan).
- **Grup Chat**: Fitur komunikasi grup keluarga (sedang dalam pengembangan).
- **Pengumuman Penting**: Menampilkan pengumuman penting untuk keluarga (sedang dalam pengembangan).

## Teknologi yang Digunakan

- **Bootstrap 5**: Untuk desain dan layout responsif.
- **Google Fonts**: Untuk tipografi yang bersih dan konsisten.
- **Flatpickr**: Untuk pemilih tanggal yang user-friendly.
- **jQuery**: Untuk interaksi dan manipulasi DOM.

## Struktur Proyek

- **`index.html`**: Halaman utama aplikasi yang berisi struktur HTML dan elemen antarmuka pengguna.
- **`styles/style.css`**: Berkas CSS kustom untuk styling tambahan.
- **`js/script.js`**: Berkas JavaScript untuk logika aplikasi.
- **`vendor/`**: Berisi pustaka eksternal seperti Bootstrap, jQuery, dan Flatpickr.

## Catatan

Saat ini, proyek ini masih dalam tahap pengembangan dan beberapa fitur belum sepenuhnya diimplementasikan. Dokumentasi dan instruksi penggunaan akan diperbarui sesuai dengan kemajuan proyek.
