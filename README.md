# KeluargaKu

**KeluargaKu** adalah aplikasi web yang dirancang untuk manajemen kegiatan keluarga, seperti tugas, pengumuman penting, dan pengaturan keuangan. Menggunakan teknologi seperti Bootstrap 5, Google Fonts, dan Flatpickr, aplikasi ini menawarkan antarmuka yang responsif dan mudah digunakan.

## Fitur yang Direncanakan

1. **Dashboard Utama**: Ringkasan kegiatan dan pengingat penting.
2. **Manajemen Tugas**: Formulir untuk menambah dan melacak tugas.
3. **Sticky Notes**: Menyimpan catatan penting dalam bentuk sticky notes digital.
4. **Finansial**: Melacak transaksi keuangan dan pengeluaran.
5. **Kontak Darurat**: Menyimpan informasi kontak darurat.
6.  **Daftar Belanja**: Membuat dan mengelola daftar belanjaan.
7.  **Media Galeri**: Menampilkan galeri media keluarga (sedang dalam pengembangan).
8.  **Berkas Penting**: Menyimpan berkas penting (sedang dalam pengembangan).
9.  **Acara dan Tradisi Tahunan**: Mengelola acara dan tradisi tahunan (sedang dalam pengembangan).
10.  **Pengaturan Anggota Keluarga**: Mengelola pengaturan anggota keluarga (sedang dalam pengembangan).
11.  **Grup Chat**: Fitur komunikasi grup (sedang dalam pengembangan).
12.  **Pengumuman Penting**: Menampilkan pengumuman penting (sedang dalam pengembangan).

## Teknologi yang Digunakan

1. **Bootstrap 5**: Desain dan layout responsif.
2. **Google Fonts**: Tipografi yang bersih dan konsisten.
3. **Flatpickr**: Pemilih tanggal yang user-friendly.
4. **jQuery**: Interaksi dan manipulasi DOM.

## Struktur Proyek

1. **`index.html`**: Halaman utama dengan struktur HTML dan elemen antarmuka pengguna.
2. **`styles/style.css`**: CSS kustom untuk styling tambahan.
3. **`js/script.js`**: JavaScript untuk logika aplikasi.
4. **`vendor/`**: Pustaka eksternal seperti Bootstrap, jQuery, dan Flatpickr.

## Catatan

Proyek ini masih dalam tahap pengembangan. Beberapa fitur belum sepenuhnya diimplementasikan, dan dokumentasi akan diperbarui sesuai dengan kemajuan proyek.
